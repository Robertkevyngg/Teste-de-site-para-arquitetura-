Como usar este editor

  1. Edite os dados nos formulários abaixo — mudanças ficam guardadas no seu navegador automaticamente.
  2. Quando terminar, clique em "Baixar arquivo" no topo. O navegador vai salvar um arquivo chamado projects.json.
  3. Toque em Enviar ao GitHub — selecione o arquivo baixado e confirme.
  4. Em cerca de 1 minuto, o site fica atualizado automaticamente.
