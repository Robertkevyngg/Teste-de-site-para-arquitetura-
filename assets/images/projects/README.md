# Pasta de imagens dos projetos

Coloque aqui as imagens que serão referenciadas em `data/projects.json`.

**Sugestão de nomenclatura:**
```
casa-mirante-01.jpg
casa-mirante-02.jpg
loft-industrial-01.webp
```

**Referência no JSON:**
```json
"cover": "assets/images/projects/casa-mirante-01.jpg"
```

**Recomendações:**
- Proporção das capas: 4:5 (1200×1500 px).
- Formato: JPG ou WebP, otimizado (< 300 KB por imagem).
